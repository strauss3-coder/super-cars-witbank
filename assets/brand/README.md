# Brand files

`logo-source.jpg` is the master artwork as supplied by the dealership, on a
white background. It is the only copy, so it is kept here even though the site
never loads it.

The two files the site actually uses are generated from it:

| File | Where |
|---|---|
| `logo.png` | the header, which sits on white — the artwork as drawn |
| `logo-light.png` | the footer and the portal, which sit on black — the black ink lifted to white so the car outline and the tagline do not disappear, with the red left alone |
| `icon-180.png`, `icon-512.png` | the browser tab and the iOS home screen — the car mark alone on the brand red, because the wordmark is an unreadable smudge at 32px |

To regenerate them after replacing the master, see the block in the project
history under "Cut out the logo for light and dark backgrounds".
